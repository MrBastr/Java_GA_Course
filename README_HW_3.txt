# Система управления транспортом

## Описание проекта

Проект представляет собой объектно-ориентированную систему для моделирования различных видов транспорта. Реализована иерархия классов, демонстрирующая принципы ООП и современные возможности Java.

## Архитектура решения

### Основные компоненты

#### 1. Перечисления (Enum)
- **FuelType** - типы топлива (бензин, дизель, электричество, керосин, ветер)
- **TransportType** - категории транспорта (наземный, воздушный, водный)

#### 2. Двигатели (Запечатанные классы)
- **Engine** (абстрактный, запечатанный) - базовый класс для всех двигателей
- **CombustionEngine** - двигатель внутреннего сгорания
- **ElectricEngine** - электродвигатель  
- **JetEngine** - реактивный двигатель

#### 3. Транспортные средства (Запечатанные классы)
- **Transport** (абстрактный, запечатанный) - базовый класс для транспорта
- **Car** - автомобиль с уникальным методом `honk()`
- **Bicycle** - велосипед (без двигателя) с методом `ringBell()`
- **Airplane** - самолет с методами `takeOff()` и `land()`
- **Ship** - корабль с методом `soundHorn()`



### ️ Принципы ООП
- **Инкапсуляция**: все поля приватные с геттерами
- **Наследование**: иерархия Transport → конкретные виды транспорта
- **Полиморфизм**: переопределение методов move() и stop()
- **Абстракция**: абстрактные классы и методы



###  Отношения между классами
- **Наследование**: Car → Transport, CombustionEngine → Engine
- **Ассоциация**: Transport имеет Engine
- **Реализация**: переопределение абстрактных методов

## Функциональность

### Основные операции
- Создание объектов транспорта
- Управление движением (start/stop)
- Отображение информации о транспорте
- Уникальные действия для каждого типа транспорта

## Пример использования


// Создание автомобиля
Car car = new Car("Toyota", 220, 4, FuelType.PETROL, 
    new CombustionEngine("V6", 250, FuelType.PETROL));

// Использование полиморфизма
Transport transport = car;
transport.move(); // Вызовется реализация Car
```

## Преимущества архитектуры

1. **Расширяемость**: Легко добавить новый тип транспорта
2. **Безопасность типов**: Запечатанные классы предотвращают неконтролируемое наследование
3. **Гибкость**: Возможность работать с транспортом через базовый класс
4. **Чистота кода**: Разделение ответственности между классами

## Технологии

- Java 17+ (для запечатанных классов)
- Объектно-ориентированное программирование
- Принципы SOLID
